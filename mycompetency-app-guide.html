myCompetency
Report Generator

Upload your competency data files and generate the AI executive PPTX deck and Excel export packs — no installation, no local files needed.

competency-report.politeisland-f996f0b0.eastus2.azurecontainerapps.io

How to use

1

Upload both source files

In the sidebar, upload the Master File (MyC Report Excel — Details sheet, header row 2) and the Result / Dump File (assessment proficiency dump). Both are required before the app loads data.

2

Select Business Group scope

Choose All (Tech_Song + Tech_Adobe Platform combined), or filter to a single business group. The roster and all metrics update instantly.

3

Generate reports or download exports

Click Generate AI Executive Report for the PPTX deck, or use the three Excel export buttons to download individual packs. All files are built on-demand and streamed directly to your browser.

Reports & exports

✦

AI Executive Report (PPTX)

AI-written narrative deck powered by Azure OpenAI. KPI cards, career-level breakdown, skill gap analysis, top projects, and proficiency distribution — ready to present.

📊

Skill Chase Workbook

One sheet per primary skill — lists every resource with No Assessment or Below Target status, sorted by action priority and career level.

👥

People Lead Follow-up Pack

Executive summary, project-level action table, full resource chase detail grouped by project, skill gap summary, and career-level health — all in one workbook.

📋

No Assessment Action List

All resources without a recorded assessment — EID, Primary Skill, and Details action required — sorted by Details so follow-ups can be batched efficiently.

Data security

🔒

Files are never stored

Uploaded files are processed entirely in RAM. There are no disk writes, no database, and no persistent storage. When the container scales to zero (after idle), all data is gone. Nothing is logged to Azure beyond standard infrastructure metrics.

⚡
Upload note: Source files are typically 20–35 MB. Upload time depends on your connection speed — expect 15–40 seconds for large files. Processing itself takes under 3 seconds once the file is received.

Tips

File requirements

  • Master File: Excel (.xlsx), sheet named Details, header on row 2
  • Result File: Excel (.xlsx), contains Enterpriseid, SkillName, proficiency
  • Business Groups supported: Tech_Song, Tech_Adobe Platform
  • Skill type filtered to: Primary only

Proficiency levels

  • P0 — Rank 0 (lowest)
  • P1 — Rank 1
  • P2 — Rank 2 · Target for CL 11–12
  • P3 — Rank 3 · Target for CL ≤ 10
  • Expert eligible — Rank 4
